PPT Generation API v1

第一版公共 API 只开放：已有结构化大纲 → 逐页描述 → 逐页图片。

公共接口使用 API Key，不接受网页端登录 Token。API Key 归属于现有用户，因此项目隔离、用户模板和积分账户沿用现有系统。

1. 数据库迁移

cd backend
alembic -c alembic.ini upgrade head

迁移 027_public_ppt_api 会新增 api_keys 和 public_ppt_generations。

2. 创建 API Key

用户登录网页 API 后创建密钥：

curl -X POST http://localhost:5000/api/api-keys \
  -H "Authorization: Bearer <login-token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"my-integration","expires_in_days":365}'

响应中的 data.key 只返回一次。公共 API 请求头：

Authorization: Bearer lt_live_xxxxxxxx.xxxxxxxxxxxxx
POST   /api/api-keys
GET    /api/api-keys
DELETE /api/api-keys/{api_key_id}

3. 提交 PPT 生成

curl -X POST http://localhost:5000/v1/ppt-generations \
  -H "Authorization: Bearer <api-key>" \
  -H "Idempotency-Key: order-20260723-001" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "智慧农业项目汇报",
    "outline": [
      {
        "part": "项目认知",
        "title": "行业正在进入智能种植阶段",
        "points": ["传统生产依赖经验", "环境参数缺少闭环"]
      },
      {
        "part": "解决方案",
        "title": "构建水肥环境协同控制系统",
        "points": ["多传感器采集", "智能策略控制", "异常闭环处置"]
      }
    ],
    "visual": {
      "template_id": null,
      "style": "绿色农业科技感，专业，简洁",
      "aspect_ratio": "16:9"
    },
    "options": {
      "language": "zh",
      "detail_level": "default",
      "harness_template": null,
      "description_requirements": "每页突出一个明确结论",
      "extra_requirements": "图片中的中文文字必须清晰可读"
    }
  }'
  • outline 必填，默认最多 30 页，可通过 PUBLIC_API_MAX_PAGES 调整。
  • outline[].title 必填，points 必须为字符串数组。
  • visual.template_id 引用当前账户已经上传的用户模板。
  • 没有模板、风格或 Harness 场景包时，系统使用默认专业商务风格。
  • Idempotency-Key 可选；相同键与相同内容返回原任务，不同内容返回 409。
  • 提交时分别预占逐页描述和图片生成积分。

4. 提交响应

成功提交返回 HTTP 202：

{
  "success": true,
  "data": {
    "generation_id": "...",
    "status": "QUEUED",
    "current_stage": "descriptions",
    "progress": {
      "stage": "descriptions",
      "total": 2,
      "completed": 0,
      "failed": 0
    },
    "links": {
      "self": "/v1/ppt-generations/...",
      "pages": "/v1/ppt-generations/.../pages"
    }
  }
}

5. 查询状态和结果

GET /v1/ppt-generations/{generation_id}
GET /v1/ppt-generations/{generation_id}/pages
GET /v1/ppt-generations/{generation_id}/pages/{page_id}/image
GET /v1/templates

任务状态：QUEUED、PROCESSING、COMPLETED、PARTIAL、FAILED。

阶段状态：descriptions、images、completed、failed。

PARTIAL 表示逐页描述完成但部分图片失败，页面结果中的 status 可定位失败页。

6. 第一版边界

当前公共任务仍运行在现有进程内线程池中；服务进程重启不会自动恢复正在执行的任务。第一版不包含 webhook、单页重试和任务取消。生产部署前建议迁移到 Redis + Celery/RQ 等可恢复队列。
