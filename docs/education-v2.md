## 我的空间：五分类（2026-09-26）

按用户提供的截图实现五个横向标签，默认“作品记录”，选择态为蓝色下划线。下方使用搜索、类型筛选、排序、分页和文件列表；窄窗口优先显示名称、状态及操作。

| 分类 | 数据与行为 |
| --- | --- |
| 长期文件 | 用户保存的常用文件及已关联作品的材料；支持上传、下载、重命名、复制到已有作品 |
| 临时文件 | 尚未关联作品、未转为长期保存的文件；支持长期保存，不自动清理 |
| 下载记录 | 当前用户作品目录中实际存在的导出文件；可再次下载，不推断浏览器保存成功 |
| 回收站 | 文件或作品的软删除记录；可恢复，不自动清空，不提供永久删除 |
| 作品记录 | 当前用户的教育项目；显示页数与生成状态，支持继续编辑、重命名、移入回收站 |

实现采用独立的 `education_space_entries` 元数据表，迁移版本 `033_education_space`。上传复用原有文件/素材接口；分类与回收使用 `/api/competition/space`。文件复制为独立实体和独立磁盘文件，源文件仍可复用。参考文档复制后关联作品，图片复制后由用户在工作台选择用途和成员。

关联作品（包括已回收作品）的材料不能单独移入回收站；运行中的作品任务与正在解析的材料禁止相关变更。回收作品会从首页与作品列表隐藏，旧工作台入口被阻止，恢复后内容版本和素材仍保留。通用版不应用这些分类和回收规则。

大纲、逐页描述与待补清单导出时，按内容版本写入作品导出目录，下载记录可读取对应版本。既有 PDF、PPTX 直接读取现有导出文件，不重新生成，不额外调用模型。

### 长期文件预览

长期文件列表新增“预览”按钮，在当前页面弹窗查看。图片按可用空间适配显示；PDF 本地按页渲染，可前后翻页；TXT、Markdown 直接显示文本，DOCX、PPTX 提供文字内容预览并明确说明不还原排版。保留下载原文件入口，预览失败可重试，关闭后保留分类与搜索。

预览仅使用本地文件与现有解析内容，不调用模型、不触发解析任务、不消耗积分、不向外部文档查看服务上传文件。接口沿用账号归属校验，回收站文件不可预览；图片请求使用统一认证客户端，关闭或翻页后取消未完成请求并释放图片 URL。长文本限制 12 万字符，过大的 Office 文件提示下载查看。
