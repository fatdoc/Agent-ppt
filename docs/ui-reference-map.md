# 世职赛 PPT 平台 UI 参考映射

> 审计日期：2026-07-30
> 参考目录：`UI/`
> 原则：参考图只用于视觉与交互还原，产品实现必须由真实 React 组件、路由和服务组成。

## 总体视觉语言

- 左侧固定业务导航，白色画布，深蓝正文，亮蓝为唯一主要操作色。
- 主工作区采用 16–24px 间距、细描边和轻阴影；状态使用蓝、绿、橙三类语义色。
- 页面标题、赛事上下文、保存状态和全局操作保持固定层级。
- 核心业务上下文在页面间连续传递：赛事、比赛类型、赛道、主题、项目。
- 参考图中的赛事案例仅能用于 `wvcc`（世界职业院校技能大赛）完整支持模式。

## 目标导航补充

参考图缺少但需求明确要求的一级入口：

1. PPT 工作台
2. AI 生成
3. 大纲规划
4. 大纲模板
5. 模板库
6. 在线编辑
7. 素材中心
8. 导出中心

“召唤数字员工”采用全局按钮与右侧抽屉，不占用左侧一级菜单。所有页面向抽屉提供统一的项目、赛事、主题、章节、页面、选中元素与评分点上下文。

## 参考数据纠偏

- UI 图中的“38 页”属于视觉示例。用户提供的真实《世界职业院校技能大赛通用 PPT 模板与逐字稿模板》为 **39 页**，系统内置模板以 39 页为准。
- UI 图中的“医药卫生 / 智慧养老”只作为世职赛配置示例，不生成未经用户材料验证的项目成果、数据或案例。
- 世界职业院校技能大赛可显示五项专属评分维度；其他 `GENERIC` 赛事不得显示伪造的赛事评分映射。
